# **App Name**: StudyWise AI

## Core Features:

- Text Input: Text input area for users to input text.
- Quiz Generation: Generate quizzes based on the input text using Gemini 2.5 Flash.
- Note Generation: Generate notes from the provided text using Gemini 2.5 Flash, acting as a study tool to organize and summarize.
- Flashcard Generation: Generate flashcards from the input text using Gemini 2.5 Flash.
- Content Display: Display the generated quizzes, notes, or flashcards in a readable format.
- Quiz Interaction: Allow users to interact with the generated quizzes (e.g., answer questions, get scores).
- Flashcard Interaction: Enable interaction with flashcards (e.g., flip to reveal answer, mark as known).

## Style Guidelines:

- Primary color: Light green (#B2D7B2) to evoke a sense of calm and focus conducive to studying.
- Background color: Off-white (#F5F5F5), a very light tint of the primary hue, to provide a clean and non-distracting backdrop.
- Accent color: Muted yellow (#E0C98F), analogous to green but slightly desaturated, used for highlighting key information and interactive elements.
- Body and headline font: 'Inter' sans-serif, to ensure high readability and a modern, clean feel that aids concentration. 
- Use simple, line-based icons in the muted yellow to represent different types of learning materials and actions.
- Clean and minimalist layout with ample white space to reduce clutter and promote focus.
- Subtle animations for transitions and interactions to provide a smooth and engaging user experience.
